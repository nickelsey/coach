# Goal
I would like to build a workout and fitness application for myself. The goal is to have a place where I can handle multiple exercise, health, fasting, potentially diet, sleep, and other pieces of information as well. One thing  really want is for the data to not just live on-device, however, but to be synced to a location that is available for anylsis in other locations - for instance, if I wanted to use an LLM to create a schedule of workouts, be able to push it directly to the backend from my laptop or desktop.

# App Requirements
1) Iphone only
2) Connectors to sensors like heart rate straps, tymewear breathing straps, my indoor trainer, etc
3) Notifications for things like fasting alerts, scheduled workouts, etc
4) Sync workouts/health data to and from apple fitness/health

# App Design
1) Homescreen with overview of metrics + quick actions perhaps? Maybe things like a button for start/stop fasting 
2) Navigation on the bottom for the categories - probably home, diet, exercise, health? Not sure what the best way to organize is yet
3) I'd like the app to be visually interesting, not a basic fitness app

# In-App Tools I would like to include
1) First tool will be a simple one, just a fasting tracker - can be as simple as a button and a timer
2) Second will be a workout calendar and tracked workouts, including sensors. We can start out with 4 types of workout plans - cycling, weight lifting, running, and mobility

# Desktop/browser application
1) Not sure if it should be browser based or native
2) A place to work on workout plans/schedules and analyze data locally
3) Potential LLM integration point for coaching/planning/analyzing
